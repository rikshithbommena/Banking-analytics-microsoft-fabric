# SQL Server Analysis

SQL Server was used to perform exploratory and business-focused analysis on the banking dataset.

## Analysis Areas

- Customer analysis
- Account balance analysis
- Transaction analysis
- Loan analysis
- Credit score analysis
- Account type analysis
- Transaction and loan aggregations
- Data quality and relationship validation

## Key SQL Skills Demonstrated

- SELECT, WHERE, GROUP BY, ORDER BY
- Aggregate functions
- JOIN operations
- CASE expressions
- Subqueries
- Date-based analysis
- Data validation
- Business-oriented analytical queries

## Database

The analysis was performed using Microsoft SQL Server and SQL Server Management Studio (SSMS).

The SQL analysis was later used as a foundation for the transformation and analytics workflow in Microsoft Fabric.
